# getboundly.com

Boundly 的官网，单个 `index.html`（内嵌 CSS 和原生 JS，中英切换），用 GitHub Pages 发布：推送到 `main` 就上线。

- 首屏是 Bridgeboard（给留学生的 Blackboard 学习面板），下载按钮指向 [HeathTeng/Bridgeboard](https://github.com/HeathTeng/Bridgeboard) 最新版本里的 `Bridgeboard-Windows.zip`，以后发新版不用改网站。
- 往下是 Boundly 的构想、Bridgit 原型和「我们守住的边界」。
- 首屏右边是可以横向滑动的截图，会每 5 秒自动翻一张（鼠标放上去或手动滑动时停下）。`assets/` 里的截图用 Bridgeboard 示例模式（`demo.bat`）截取，不含真实数据。
- 联系：hello@getboundly.com · Bridgeboard 反馈：feedback@getboundly.com
